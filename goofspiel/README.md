# Goofspiel – Simulation in Python

Modul „Objektorientierung und funktionale Programmierung“, Universität Siegen (SoSe 2026).

Simulation des Kartenspiels Goofspiel mit zwei Spielstrategien, in zwei Varianten:

- `goofspiel_funktional.py`: funktionale Umsetzung mit unveränderlichen Spielzuständen, Rekursion und `reduce`; Nebeneffekte (Ausgabe) erst am Ende
- `goofspiel_imperativ.py`: imperative Umsetzung zum Vergleich
- `helper.py`: Hilfsfunktionen (Kartenspiel, Strategien, Spielrunde)

Starten: `python3 goofspiel_funktional.py`
