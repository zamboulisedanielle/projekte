# Bücherliste – Angular

Kleine Angular-Anwendung (Angular 21, TypeScript) zum Einstieg in die Webentwicklung:

- Komponenten (`book-list`, `info-box`) und Routing
- Service `BookData`, der Bücher per `HttpClient` von einer REST-Schnittstelle lädt
- Tests mit Vitest

Starten: `npm install` und `npm start` (erwartet eine REST-API unter `http://localhost:4730/books`).
